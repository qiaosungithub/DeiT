Can a Classifier Stop Paying One Logit Per Class?

Authors: Qiao Sun <sqa24@mit.edu>; Yeyin Zhu <evazhu@mit.edu>

Modern image classifiers almost universally terminate in a C-way logit head. This project challenges that default design. We replace the linear classifier over classes with a lightweight masked bit head that predicts a binary code for the label, reducing the output dimensionality from linear in C to logarithmic in C.

Motivation

The C-way linear classifier is one of the least questioned components in modern visual recognition. Given an image representation, the default choice is to apply a dense matrix and produce one scalar logit for every class. This design is simple, differentiable, and empirically strong; consequently, it is often treated as part of the definition of supervised classification rather than as a design choice.

From an information-theoretic perspective, however, identifying one label among C possibilities requires only log2 C bits of information. A C-dimensional logit vector is therefore not a minimal description of the prediction. For example, an ImageNet-1K label can be represented by only 10 bits, while the conventional classifier emits 1000 floating-point logits. The distinction matters when the label space grows: the conventional head scales linearly in parameters, memory bandwidth, and output activations, while the number of bits needed to specify the answer grows only logarithmically.

This project asks whether the community's default practice can be relaxed. Instead of learning a direct map from visual features to C logits, we learn a map from visual features to the bits of the class identity. The resulting classifier is not intended to remove all costs associated with large label spaces; the representation still has to separate many visual categories. The narrower claim is that the final prediction head need not allocate one output channel per class.

Research question. Can a discriminative vision model replace the standard C-way logit head with a masked bit prediction head whose output dimension is proportional to ceil(log2 C), while retaining meaningful classification accuracy?

Related Work

Discrete visual tokens and masked generation

Discrete visual representation learning provides the closest technical context. VQ-VAE [2] introduced learned discrete latent codes; VQGAN [3] combined a convolutional tokenizer with a transformer prior for high-resolution synthesis; MaskGIT [4] replaced left-to-right token generation with iterative masked token prediction. These methods are generative rather than discriminative, but they expose the same output-space issue: a categorical head over a large discrete vocabulary scales with the vocabulary size.

Recent image generation work has explored alternatives to ordinary large-vocabulary token prediction. MAR [5] removes vector quantization and models continuous visual tokens using a diffusion loss conditioned on an autoregressive context. BAR [6] takes a complementary path: it keeps discrete tokens, but replaces the large token softmax with masked bit modeling. BAR shows that large codebooks can be made practical by predicting the binary representation of a token rather than scoring every codebook entry. Our method can be viewed as a discriminative analogue of this direction: the object to be generated is not an image token, but the discrete class identifier.

Large-class classification

Large-class recognition is often studied through pretraining rather than as an endpoint task. Big Transfer [7], ViT [8], and ImageNet-21K Pretraining for the Masses [9] all demonstrate that large supervised taxonomies produce transferable visual representations. Ridnik et al. [9] further analyze why direct classification on such taxonomies is difficult: single-label training is efficient but semantically inconsistent, multi-label training is more expressive but becomes an extreme multi-task problem, and semantic softmax uses the WordNet hierarchy to reduce this mismatch. Differentiable Top-k Classification Learning [10] optimizes ranking metrics directly on ImageNet-scale label spaces. These works improve training objectives or label semantics, but the output layer remains tied to the number of classes.

Method

Label encoding and diffusion head

Let y in {0, ..., C - 1} denote the class index. We encode the class as an LSB-first binary vector b(y) in {0,1}B, where

B=⌈log2C⌉.

The backbone first maps the image to a visual representation. The masked bit head is intentionally lightweight: for each bit position, the head receives one of three tokens, 0, 1, or MASK. A small learned embedding for these bit tokens is concatenated with the image CLS feature and passed through a two-layer GELU MLP. The output contains two logits per bit. Thus the head predicts 2B scalar logits rather than C class logits. More expressive designs are possible, including a cross-attention block in which bit queries attend to image patch tokens. In our experiments, however, the naive MLP head was surprisingly strong and offered the best accuracy-compute tradeoff in the final recipe.

Training objective

Training follows the standard masked diffusion pattern, but the object being diffused is the class-bit vector rather than an image. For each training example, we sample a binary mask, replace the hidden bit positions by MASK tokens, and train a network ftheta to reconstruct the original bits:

L= CE ( b, fθ (I,b⊙mask) ).

The cross-entropy is evaluated on the masked positions. This objective is deliberately close to masked image generation losses: the model sees a partially observed discrete object and predicts the missing entries. The difference is that the discrete object has only B bits, so the reconstruction head is small.

Inference

At inference time, the lowest-cost classifier starts from an all-MASK bit sequence and predicts every bit once. We also evaluate a 4-step confidence decoder: at each step the head predicts all currently masked positions, and the most confident subset is fixed before the next step. This is the discriminative analogue of iterative masked generation.

We also evaluate an explicit class-code scorer. Instead of generating one bit string, the scorer enumerates the legal class codes and assigns each class a path-dependent score by revealing bits sequentially and accumulating their log probabilities. This produces a full ranking of the valid classes, but it is no longer the logarithmic-cost operating point: with P one-bit reveal paths, the scorer makes P log2C passes over C candidate codes. Each pass still uses the lightweight bit head. We use this setting to test whether additional inference compute can recover recall@K.

Efficient multi-mask training

Diffusion-style training is often slower than ordinary classification because the model must learn many noise levels or mask patterns. A single image-label pair is not just one supervised example; it represents many possible partially masked bit strings. We exploit the fact that the image encoder is much more expensive than the bit head. For each image, the backbone is run once. The resulting feature is then repeated across K independently sampled bit masks, and only the lightweight head is evaluated K times.

This produces many masked-bit training samples while adding little memory pressure relative to another full image forward pass. In the final configuration, K = 80. The ablation below shows that increasing the number of mask samples per image forward substantially accelerates early learning.

Mixup and CutMix supervision

Mixup and CutMix produce soft labels. Collapsing those labels by argmax creates a mixed image with a single hard bit target, which is especially noisy for a bit-level objective. In the final recipe we use soft_top2: for each image we create K masked-bit samples, take the top two soft-label classes, and split the K samples between their bit codes in proportion to the mix weight. With K = 80 and a 50/50 CutMix sample, 40 masked-bit samples train toward one class and 40 toward the other.

Experimental Setup

On ImageNet-1K we trained DeiT-B variants with a masked bit head for 330 epochs, batch size 1024, AdamW, learning rate 5e-4, weight decay 0.02, stochastic depth 0.05, and no CE shortcut or backbone warm-start. We use DeiT-B [1] as a standard supervised ViT backbone; the experimental variable is the replacement of the terminal classifier head. The best configuration used K=80, uniform mask ratios, low augmentation, mixup alpha 0.8, CutMix alpha 1.0, switch probability 0.5, and soft_top2 label allocation.

For ImageNet-1K inference, we evaluate both generated-label decoding and explicit scoring of all 1000 legal class codes on the full 50,000-image validation set. The strongest explicit scorer uses 20 random one-bit reveal paths and aggregates them by mean rank.

On ImageNet-21K-P we use the processed winter21 split (10,450 classes) [9] and encode class ids as 14-bit LSB-first vectors. The masked-bit DeiT-B trained for 30 epochs at batch size 1024 on 8 GPUs with the same head and optimizer settings as the ImageNet-1K recipe: K=80, soft_top2 supervision, AdamW (b2=0.95, lr 5e-4, wd 0.02), label smoothing 0.1, stochastic depth 0.05, mixup α=0.8, CutMix α=1.0, switch probability 0.5, low augmentation. A standard single-label cross-entropy softmax baseline was trained from the same DeiT-B initialization on the same data and budget.

Validation is on the full 522,000-image set. We report two decoders for the masked-bit head: 16-step iterative bit decoding, and explicit class-code scoring with 1, 5, and 20 one-bit LSB reveal paths under rank-mean aggregation. The 16-step decode and the 1-path scoring run cover a large fraction of the full set (about 38,000 images for 1-path). The 5- and 20-path scoring runs are more expensive (each additional path multiplies inference cost by C = 10,450) and are reported on ~1,400 and ~360-image prefixes of the same validation stream, at sample counts where per-batch top-1 and recall@5 had settled within ±0.5 pp.

The 30-epoch budget was intended; in practice cluster preemption and the project deadline truncated the masked-bit Run AB at epoch 21 and the softmax baseline at epoch 28. The numbers reported for both heads are from those checkpoints. Run AB's per-epoch numbers swing by ~0.2 pp over its last few epochs (Figure 3), so the truncation should not materially affect the comparisons.

A note on metrics. Top-1 throughout this report is the standard single-prediction accuracy: the fraction of validation images whose ground-truth class equals the head's top-ranked candidate. We use recall@5 rather than “top-5 accuracy” for the size-5 candidate set: under multi-path explicit class-code scoring the candidates are ordered by rank-mean across reveal paths rather than by a single probability, so they are not the “five highest probabilities” the conventional top-5 label suggests. Recall@5 has the same arithmetic value as top-5 accuracy when the ranking does come from a single probability vector (as for the softmax baselines and the standard ImageNet-1K results we cite), so the comparison across rows in Tables 1, 2, and 4 is well-defined.

Future Directions

The same principle can extend beyond image classification. Many vision tasks use large structured output spaces, but still train with dense discriminative losses. Semantic segmentation is a natural example: instead of predicting an independent cross-entropy distribution at every pixel, one could represent the segmentation mask as a discrete object and generate it with a diffusion-style decoder. This would move the model closer to structured mask generation, where spatial consistency is part of the output process rather than only a byproduct of the backbone.

Another direction is to replace ordinary binary class ids with learned or hierarchy-aware codes. Such codes could make nearby bit strings correspond to semantically nearby classes, reduce the cost of bit errors, and connect the logarithmic head more directly to the taxonomy of large recognition datasets.

Limitations

The masked-bit head is class-efficient, but it loses some conveniences of a standard logit head. A softmax classifier directly produces a normalized distribution over all classes. Our decoder instead produces one or several class codes. As a result, computing calibrated per-class probabilities is not immediate; it requires either additional scoring over candidate codes or an expensive pass over all valid class codes.

The binary code itself is also a modeling choice. In this implementation, class ids are encoded as ordinary binary integers, so nearby codes are not necessarily semantically related. This makes bit errors uneven: flipping a high-order bit can move the prediction to an unrelated class. In addition, when C is not a power of two, some bit strings are invalid class labels. The model learns to avoid most invalid codes, but the issue is absent in a conventional C-way head. On ImageNet-21K-P, 36% of the 214 bit patterns are invalid class ids, versus 2.3% of 210 patterns on ImageNet-1K. Even so, the 16-step iterative decoder produced no invalid codes on the validation set — the model learns to avoid the invalid region more aggressively than the prior on bit-pattern legality alone would suggest.

Finally, there is a tradeoff between logarithmic-cost decoding and recall@K evaluation. Generated-label decoding preserves the intended low-cost inference path, but it does not rank every class. Explicit class-code scoring produces a size-K candidate set over legal classes, but its cost scales with C because every candidate code is scored.

Discussion

The principal positive result is that a classifier can learn a nontrivial visual decision rule without a C-way logit head. The masked-bit head reaches 78.34% low-cost generated-label accuracy on ImageNet-1K, and explicit class-code scoring improves the same checkpoint to 78.87% top-1 and 92.73% recall@5 at the 20-path rankmean operating point (the best top-1 across all scoring settings, 5-path logmeanexp, is 78.91%). On ImageNet-21K-P the same head reaches 44.45% top-1 and 73.13% recall@5 with one-path explicit scoring, rising to 74.65% recall@5 with 5-path rank-mean scoring; a DeiT-B softmax baseline trained from the same initialization for the same 30 epochs lands at 48.45% / 78.76%. This is a feasibility result for class-efficient output heads: the number of predicted output channels is 20 on ImageNet-1K and 28 on ImageNet-21K-P, rather than 1000 or 10,450.

The main limitation is that bit-factorized prediction is not yet a drop-in accuracy replacement for softmax classification. Accuracy remains below conventional classifiers, especially on ImageNet-1K. Some of this gap may be attributable to the unresolved DeiT reproduction gap in our codebase, but the ablations also indicate genuine modeling challenges.

The experiments also show that the masking protocol is central to the method. Early runs were weak when mixed images were supervised by hard argmax labels and evaluation used only all-mask single-step decoding. Correcting mixup/CutMix supervision, increasing the number of mask samples K, and using iterative decoding changed the method from a near-random baseline into a mature 76-78% ImageNet-1K classifier. This is consistent with the BAR result in generative modeling: masked bit prediction is effective only when training masks and inference schedules are treated as first-class components of the model.

The inference sweep clarifies where the method is strong. Extra scoring compute gives a large recall@5 improvement, from 80.17% under all-mask class scoring to 92.73% under 20 random one-bit paths. Top-1 improves much less, from 78.34% low-cost iterative decoding to 78.91% under the best explicit scorer. This suggests that the model often assigns useful probability mass to the right neighborhood of labels, but its first choice remains the main bottleneck.

The same recall@5 pattern appears on ImageNet-21K-P. Switching from 16-step iterative decoding (49.75% recall@5) to one-path explicit class-code scoring (73.13%) closes most of the gap to softmax recall@5 (78.76%) on a 10× larger label space; the remaining gap is roughly 4 pp at 5-path scoring (74.65% vs 78.76%). Top-1 behaves differently here: adding paths and rank-mean aggregation gives a further small recall@5 gain (73.13% → 74.65% at 5 paths, 74.44% at 20 paths) but costs about two points of top-1 (44.45% → 42.50% at 5 paths, 43.06% at 20 paths). This trade-off is much smaller on ImageNet-1K (5-path logmeanexp 78.91 vs 20-path rankmean 78.87, a 0.04 pp drop) than on ImageNet-21K-P (1.95 pp). We suspect it is partly the larger label space — with 10× more candidate codes, rank-mean disagreement across paths is more frequent — and partly the much shorter training budget on ImageNet-21K-P, which leaves first-bit predictions less sharp and therefore more sensitive to path-to-path noise.
