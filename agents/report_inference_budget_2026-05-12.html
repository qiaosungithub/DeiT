2. Scoring Formula

For a class code y and fixed unmask path S_1...S_T, score all 1000 legal ImageNet classes explicitly:

log p_theta(y | x; path) = sum_t sum_{i in S_t} log p_theta(y_i | x, y_{U_{t-1}}, mask_t)
U_{t-1} = S_1 union ... union S_{t-1}

This unifies the mask process during scoring. Path dependence is real, so we ablate LSB-first, MSB-first, random fixed paths, and path ensembles.

4. Interpretation

Explicit per-class scoring is the right direction for large inference budget. The gain is mostly top-5: all-mask top5 80.166 to one-bit multi-path top5 92.734, a +12.568 point jump without any training.

Increasing path granularity from 4 chunks to 10 one-bit steps gives a real top5 gain: best 4-step top5 90.126 to best 10-step top5 92.734. Adding more paths has diminishing but nonzero return: 2-path 92.432, 5-path 92.556, 10-random/12-path 92.684, 20-random 92.734. For top-5, rankmean aggregation is currently best; top-1 is saturated around 78.9.
