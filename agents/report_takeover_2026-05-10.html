3. 技术问题：Mask Ratio 下 Loss 求和还是平均

当前实现（masked_diffusion_loss）是：对所有 masked token 的 CE 求和后，除以 masked token 总数（token-level mean）。

  • 形式：L = sum_i sum_j m_ij * CE_ij / (sum_i sum_j m_ij)。
  • 效果：每个 masked token 权重相同；高 mask-ratio 样本因为 masked token 更多，整体贡献更大。

可选替代：先做每样本 masked mean，再对 batch 平均（sample-level mean）。

  • 形式：L = mean_i [ sum_j m_ij * CE_ij / max(sum_j m_ij,1) ]。
  • 效果：每个样本权重相同；但低 mask 样本会被相对放大，方差更大。

建议：先保留 token-level mean 作为主线（更稳，和常见 masked objective 一致），并把 sample-level mean 作为一个独立 ablation 开关验证。
