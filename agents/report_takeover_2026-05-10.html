1. Research Goal

项目目标是把 DeiT ImageNet 分类的标准 1000-way logit head + CE loss 替换为 log2(N) bit 表示的 masked diffusion head。ImageNet-1K 用 10 bits 表示类别，训练时随机 mask bit 并做 bit-wise CE，推理时从全 mask 做 single-step 或 iterative decoding。

  • Phase 1: 复现 DeiT-Base baseline，目标 paper 81.8% top-1。
  • Phase 2: 实现 masked diffusion head，验证纯 diffusion classification 是否可行，并 ablate head 结构、mask schedule、sampling steps、训练长度与增强正则。

5. Phase 2 Implemented Features

  • Masked diffusion label encoding: class_to_bits / bits_to_class，10-bit LSB-first 类别编码。
  • Diffusion loss: masked positions 上做 bit-wise CE，默认 token-level mean。
  • Eval: 同时记录 single-step all-mask accuracy、iterative decoding accuracy、invalid code rate。
  • Mask schedule: 支持 uniform 与 logit_normal。
  • Mixup fix: diffusion 训练关闭 mixup/cutmix，避免混合图像被 argmax 成单标签 bit 的监督噪声。
  • Aux CE branch: 可选 head_aux_ce + aux_ce_loss_weight，用于诊断 CE 监督是否帮助 backbone。
  • Backbone warm-start: load_backbone_from，从 Phase 1 checkpoint 复制非 head 参数，优化器重新初始化。
  • K-mask CLS reuse: n_masks_per_image，每张图只 encode 一次，重复 K 个 mask 训练 head。
  • Tiny-bit MLP head: bit embedding 缩到 8 维，CLS decoder MLP hidden 默认 3072。
  • Cross-attention head: bit queries 对全 token memory（CLS + patch tokens）做 cross-attention。

9. Interpretation

  • Pure diffusion is viable: Run N 已经在 ep119 达到 59.06% / iterative 62.80%，不再是“训不动”。
  • K10 multi-mask 是高 ROI: Run M/N 早期曲线远强于旧 C/D/E/G，说明增加每图 mask 监督密度有效。
  • Low augmentation helps: Run N 明显领先 Run M，说明 diffusion head 对过强 augmentation/regularization 更敏感。
  • 旧 attention head 路线弱: E/G 在 ep139 仍很低，继续堆旧 head 容量价值不高。
  • Aux CE / warm-start 是强 diagnostic: H/I 说明 backbone 语义质量是瓶颈，但按用户决策不作为当前主线。
