2. Method

Current training eval only did greedy all-mask bit argmax and 4-step confidence iterative decoding. The new evaluator explicitly scores all 1000 legal ImageNet class codes under fixed mask processes.

log p_theta(y | x; path) = sum_t sum_{i in S_t} log p_theta(y_i | x, y_{U_{t-1}}, mask_t)
U_{t-1} = S_1 union ... union S_{t-1}

Because masked diffusion is path-dependent, we ablated all-mask scoring, 2/4 chunk paths, one-bit 10-step paths, random path ensembles, probability aggregation, and rank aggregation.

3. Best Method Implementation

The best top-5 result uses 20 random one-bit unmask paths + rankmean aggregation. It is implemented in inference_score_ablation.py; the key functions are _chunks_for_method and _make_eval_step.

Class codesOnly the 1000 legal ImageNet-1K classes are scored. Class labels are converted to binary with models.class_to_bits(jnp.arange(1000)). Bits are LSB first, matching training and models.bits_to_class.
Image preprocessingValidation split uses the existing ImageNet eval pipeline: resize to int(224 / 0.875) = 256, center crop 224, convert to tensor, normalize with ImageNet mean/std. No augmentation or mixup is used at inference.
Backbone computeFor each image batch, the ViT backbone is run once to get the CLS feature: model.encode(images, train=False). The CLS tensor is reused for all class-code scoring, so the expensive image encoder is not repeated per path.
Random pathsFor each path rand0 ... rand19, create a deterministic random permutation of bit indices 0..9 using jax.random.permutation(PRNGKey(seed), arange(10)). Each path has 10 chunks, one bit per chunk, so it is a one-bit autoregressive unmask process.
Path scoringInitialize context to all MASK tokens 2 with shape (B, 1000, 10). For each bit chunk in the path, flatten to (B*1000, 10), repeat CLS to (B*1000, dim), call model.decode_diffusion_from_cls(cls, masked_bits=context), take log_softmax over bit values, add the log-prob of each candidate class's true bit, then write that bit into context. This implements sum_t log p(y_{S_t} | x, y_{U_{t-1}}, mask_t).
Per-path rankingAfter each path has a score for all 1000 classes, sort classes descending by path score. Convert each class to a rank 0..999, where rank 0 is best.
Rankmean aggregationAverage ranks across the 20 paths, then use -mean_rank as the final class score. The top-5 classes are the five highest -mean_rank values. This is calibration-light: it uses ordering from each path rather than trusting raw log-prob scale across paths.
Compute budgetPer image: one ViT encoder pass plus 20 * 10 = 200 MLP diffusion-head decode steps, vectorized over the 1000 legal class codes. Full 50k ImageNet-1K val with batch size 32 took 908.38s on the local 4-core TPU setup.
Why no invalid-rate issueThe scorer never decodes arbitrary 10-bit outputs into the 1024-code space. It ranks only valid class ids 0..999, so top-k candidates are always valid ImageNet classes.

5. Main Findings

  • Explicit class scoring works: top5 improves from all-mask class scoring 80.166% to 92.734%, a +12.568 point gain without training.
  • Inference budget scales: best top5 improves from 4-step 90.126% to 2-path 10-step 92.432%, 5-path 92.556%, 10-random 92.684%, and 20-random 92.734%.
  • Returns are diminishing: 10-random to 20-random adds only +0.050 top5, so blindly adding paths is no longer the best use of time.
  • Path score calibration is imperfect: rankmean/RRF beats probability aggregation for top5; logmeanexp gives better top1 but lower top5.
  • Top1 is saturated: best observed top1 is about 78.916%, close to old iterative 78.336% plus only +0.58.

7. Recommended Next Step

Do not keep blindly increasing random paths first. The next useful experiment is targeted candidate generation or calibration: use a cheaper decoder to propose a candidate pool, then apply explicit path scoring/rank aggregation only to that pool with more diverse paths or test-time augmentation. This should improve cost-effectiveness versus another raw 40-path full-class sweep.
