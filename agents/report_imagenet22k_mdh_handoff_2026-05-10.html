DeiT + Masked Diffusion Head Handoff for ImageNet-22K

Date: 2026-05-10

Purpose: give a collaborator enough implementation and configuration detail to faithfully reproduce our current best masked-diffusion classification setup, then adapt it to ImageNet-22K.

Current best mature ImageNet-1K pure-diffusion run: Run N, tiny-bit MLP + K10 multi-mask + low augmentation, ep299 = 63.408% single-step / 67.480% iterative. Newer K40/K80/K160 and SiLU runs are still in flight; K80 GELU is now the best mid-epoch K-scaling branch (ep79 58.302/62.476), while K160 GELU is the best early K-scaling read so far (ep19 42.846/49.468), SiLU is mixed, and the full-augmentation mixup/cutmix run has been resumed because early slowness alone does not answer the overfitting/late-growth hypothesis.

Hard constraint: do not warm-start from a CE classifier, do not add an auxiliary CE loss, and do not train or rely on a standard class-logit head. Those are diagnostic shortcuts only and are considered off-target for the masked-diffusion research question.

1. Core Idea

Instead of a standard num_classes-way classification logit head, encode each class id as a short binary string and train a masked diffusion / masked bit prediction head.

  • ImageNet-1K: ceil(log2(1000)) = 10 bits.
  • ImageNet-22K with 21,841 classes: ceil(log2(21841)) = 15 bits.
  • Input to the diffusion head is a partially-masked bit sequence with tokens 0, 1, and MASK=2.
  • Loss is bit-wise CE on masked positions only.
  • Eval reports single-step all-mask decode and iterative 4-step decode.

2. Current Best Architecture

The best pure-diffusion direction is not the attention head. It is a small-bit-embedding, high-capacity CLS-conditioned MLP.

3. Important Implementation Details

Bit encoding

def class_to_bits(labels, n_bits):
    # labels: (B,) int32, returns (B, n_bits), LSB first
    powers = (2 ** jnp.arange(n_bits)).astype(jnp.int32)
    return ((labels[:, None] // powers) % 2).astype(jnp.int32)

def bits_to_class(bits):
    powers = (2 ** jnp.arange(bits.shape[-1])).astype(jnp.int32)
    return jnp.sum(bits * powers, axis=-1)

Masked diffusion loss

targets = jax.nn.one_hot(bits, 2)                 # (B*K, n_bits, 2)
per_bit_loss = optax.softmax_cross_entropy(logits, targets)
loss = (per_bit_loss * bit_mask).sum() / (bit_mask.sum() + 1e-8)

This is a token-level mean: every masked bit has equal weight. We have not yet validated sample-level normalization.

K-mask training path

# Encode once
cls = model.encode(images)                         # (B, 768)
cls = repeat(cls, K, axis=0)                       # (B*K, 768)

# Repeat labels/bits
bits = repeat(class_to_bits(labels), K, axis=0)    # (B*K, n_bits)

# For every repeated sample, draw t ~ Uniform(0,1), then mask each bit independently
bit_mask = Bernoulli(t)                            # 1 = masked
masked_bits = where(bit_mask, MASK=2, bits)

# Decode with MLP head
logits = model.decode_diffusion_from_cls(cls, masked_bits)
loss = masked_diffusion_loss(logits, bits, bit_mask)

Mask schedule

Use uniform: sample t ~ U(0,1) per repeated image-mask view, then independently mask each bit with probability t. Logit-normal was worse in earlier attention-head runs.

Eval

  • Single-step: all bits masked, one forward pass, argmax every bit.
  • Iterative: 4-step MaskGIT-style confidence unmasking; current eval reports eval_accuracy_iter.
  • For ImageNet-22K, do not silently clip invalid codes to the last class in final reporting. Count predicted codes >= num_classes as invalid/wrong and report invalid rate. The 1K code currently clips for historical reasons.

5. Changes Required for ImageNet-22K

  • Set NUM_CLASSES = 21841 or your exact class count.
  • Set n_bits = ceil(log2(NUM_CLASSES)); for 21,841 classes this is 15.
  • Make sure ViT(..., num_classes=NUM_CLASSES, n_bits=15).
  • Parameterize all hardcoded 1000, NUM_CLASSES=1000, and NUM_BITS=10 constants.
  • In eval, track invalid_rate = mean(pred_class >= NUM_CLASSES). For 22K, 15 bits gives 32,768 possible codes, so the invalid-code space is large: 32768 - 21841 = 10927 invalid codes, about 33.3% of the bit code space.
  • Training labels are always valid, so invalid codes are mainly an inference/eval issue.

7. Why E and G Were So Low

E/G are not the successful K10 MLP architecture. They are older attention-head experiments with n_masks_per_image=1 and full DeiT augmentation/regularization.

  • E: ViT_base_mdh_zero_init, old CLS+bit-token attention head, inner_dim=256, 2 layers, 4 heads, final bit projection zero-initialized.
  • G: ViT_base_mdh_large, old CLS+bit-token attention head, inner_dim=512, 4 layers, 8 heads.
  • Both used K=1, so each image gives only one random mask supervision view per step.
  • Both used stronger augmentation/regularization: RandAugment on, reprob 0.25, repeated_aug 3, weight_decay 0.05, stochastic_depth 0.1.
  • E's zero-initialized output projection likely made early learning especially slow: all bit logits start symmetric and the model has to break out from weak masked-bit gradients.
  • The old attention head spent capacity modeling interactions among 10 bit tokens. The successful MLP instead uses CLS semantics directly with a high-capacity 3072-d decoder and very cheap bit conditioning.

8. K Scaling and Memory Estimate

K-mask training reuses the ViT backbone output. Increasing K mainly scales the small MLP diffusion head, not the ViT backbone.

For ImageNet-22K with n_bits=15, MLP input dim is 768 + 15*8 = 888, hidden dim is 3072. Rough global activation footprint for the head only:

KRough global head activationsRough per-device / 8 TPU devices
10~276 MiB~35 MiB
20~552 MiB~69 MiB
40~1.10 GiB~138 MiB
80~2.21 GiB~276 MiB

This is a rough lower bound before XLA/backward buffers, but it supports trying K=40 first. If stable, try K=80. For 1K, numbers are almost identical because 10 vs 15 bits barely changes the MLP size.

10. Minimal Porting Checklist

  • Keep the run pure: load_backbone_from='', head_aux_ce=false, no auxiliary CE loss, no standard class-logit training objective.
  • Port MLPDiffusionHead.
  • Port class_to_bits, bits_to_class, masked_diffusion_loss.
  • Implement encode once -> repeat CLS K times -> decode K masked bit views.
  • Default recommendation: disable mixup/cutmix for the first 22K reproduction. If re-enabling it for research, do not argmax mixed labels; use K-view label allocation such as diffusion_label_mode=soft_top2, where the K repeated masked-bit targets are split across the top-2 soft-label classes in proportion to their weights. The corrected full-augmentation run is currently resumed; wait for ep39/59 before using it to make a late-growth claim.
  • Use low augmentation: no RandAugment, no random erasing, repeated_aug=1.
  • Start with adamw_b2=0.95, lr=5e-4 * batch_size/512, batch_size=1024 if resources match.
  • Log: single-step acc, iterative acc, eval loss, invalid code rate, train loss, train exact-bit-sequence accuracy.
  • For ImageNet-22K, invalid code handling must be explicit because 15-bit code space has many invalid ids.
